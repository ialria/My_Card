My Card App

A simple yet elegant **Flutter business card app** that showcases personal contact information with interactive features like calling, emailing, opening social profiles, and sharing details.

✨ Features

* 📞 Direct phone call functionality
* 📧 Send email with one tap
* 🌐 Open social media profiles (Instagram, Facebook, LinkedIn)
* 📋 Copy phone number to clipboard
* 🔗 External URL launching using `url_launcher`
* 📤 Share contact details using `share_plus`
* 🎨 Clean dark-themed UI

 Getting Started

Follow these steps to run the project locally:

1️1. Clone the repository

git clone https://github.com/your-username/my-card-app.git

2. Navigate to the project folder

cd my-card-app

3. Install dependencies

flutter pub get

4.Run the app

flutter run
